## 🚀 Projetos

### Busca de Restaurantes

Projeto desenvolvido com o objetivo de facilitar a procura e a escolha de bons restaurantes.

A proposta é oferecer uma experiência simples e intuitiva para que o usuário consiga encontrar opções de restaurantes de acordo com suas preferências.

O projeto possui uma página individual com mais informações sobre sua proposta, tecnologias utilizadas e detalhes do desenvolvimento.

---

## 📄 Página individual do projeto

Ao acessar o projeto **Busca de Restaurantes**, o usuário pode visualizar uma página específica contendo informações mais detalhadas, como:

- Descrição do projeto
- Objetivo
- Tecnologias utilizadas
- Telas desenvolvidas
- Informações adicionais sobre o projeto
